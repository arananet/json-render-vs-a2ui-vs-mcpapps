# Novelty and Scope

This repository's contribution is a runnable, bounded comparison of three
concrete agent-UI SDK/adapter/host configurations with deterministic scenario
scripts, browser-facing checks, trace-derived documentation, and explicit
claim-to-evidence limits.

It does not claim a novel protocol, a formal impossibility result, an exhaustive
literature review, universal protocol rankings, or isolated protocol causality.
The fixed-order S2 observation is one specified sequential order only. The
browser MCP fixture differs from the Node fixture. A post-rename browser run
records current-source/build hashes, 18 passing tests, and nine capture hashes;
it does not erase the fixture difference or establish a controlled intervention.

Novelty remains a human scholarly judgment. This file records scope and
non-claims for review; it is not a novelty certification.
