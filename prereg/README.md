# Preregistration Record

This directory is append-only. It records planned confirmatory work and cannot
preregister observations that were already executed. Existing S1--S3 results
are retrospective and remain governed by [the execution ledger](../paper/EXECUTION.md).

The intended future tag names are `prereg-p5-v1` through `prereg-p5-v8`. They
are names only: no Git tags have been created. A future preregistration must be
committed before its corresponding new execution and must state its fixture,
outcomes, exclusions, environment, and analysis rule. Amendments are separate
files; prior records are never edited.

Current record: [prereg-p5-v1](prereg-p5-v1.md).
